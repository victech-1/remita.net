# Remita Landing Page Clone / Static Web Project

A static website built as part of my web development learning journey. This project is a front-end implementation designed to practice HTML structure and modern CSS styling.

## 🛠️ Built With

* **HTML5** – For semantic page structure and content.
* **CSS3** – For styling, layouts, and visual design.

## 📂 Project Structure

```text
remita.net/
│
├── index.html       # Main landing page
├── remmita.html     # Secondary page / alternate layout
├── remita.css       # Stylesheet for the project
└── remita_img/      # Folder containing images and assets
```

## 🚀 Getting Started


Clone the repository (or download the ZIP):

Bash
git clone [https://github.com/victech-1/remita.net.git](https://github.com/victech-1/remita.net.git)
Open the project folder in your code editor (like VS Code).

Run the site:

Open index.html directly in any web browser to view the site.

Alternative: If you use VS Code, you can use the Live Server extension to preview it with live-reload.

## 🎯 Purpose of This Project
This project was built to practice and reinforce fundamental front-end web development concepts, including:

* Structuring clean HTML documents.

* Writing modular CSS styles.

* Organizing image assets and building responsive page layouts.
